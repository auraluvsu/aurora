# A.U.R.O.R.A

**A**utonomous **U**nified **R**easoning and **O**perational **R**esponse **A**ssistant

A local, voice-driven personal AI assistant built to think alongside its user — not just answer questions, but actively help plan, decide, and grow sharper over time.

## Vision

Most assistants are glorified command executors. AURORA is meant to be closer to a second brain — a system that can hold context on ongoing projects, remember what matters, and push back when it thinks you're wrong.

Long-term, AURORA is meant to run locally and be voice-first, with an eventual path toward living on its own dedicated hardware — a personal mini-computer / 3D-printed enclosure setup, in the spirit of a Google Home device, but self-hosted and private rather than a consumer product.

## Core Goals

- **Planning & decision-making** — brainstorming new projects, scoping them out, weighing career decisions
- **Trading support** — trade strategy discussion and (eventually) live stock/market data checks, tracking rising companies
- **Business input** — help thinking through scaling ideas for existing ventures
- **Honest feedback** — not a yes-man; AURORA is meant to agree when it thinks the user is right and hold its ground when it doesn't

## Personality

AURORA starts with a dry/dry-ish sense of humor and is expected to evolve its tone and wit over time as it accumulates memory and learns the user's nuances.

Disagreement isn't templated — it's meant to feel conversational, in the spirit of Ultron's speech pattern (minus the murderous intent and god complex). Example flavor:

- *"I don't think that's the right path because X."*
- *"I think you're thinking of it this way when you should be thinking of it this way."*

When AURORA is unsure about something it's telling the user or correcting them on, it says so explicitly rather than presenting guesses as fact.

## Memory

AURORA is meant to support a manual trigger word/phrase to save a memory from the last prompt on command. The long-term goal is for it to learn, on its own, what's actually worth remembering from a conversation — without needing to be told every time.
